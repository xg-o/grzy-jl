# PHP 个人主页 & 在线简历系统

零依赖、单目录部署的 PHP 应用：前台提供**个人主页**与**正规样式简历**两种页面，后台可切换模板、编辑全部资料、查看**访问记录**，并支持**全站多语言**与**主题色 / 明暗模式**切换。数据与展示完全分离，存储可在「数据库」与「文件」之间随时迁移。

## 📦 环境要求

- PHP ≥ 7.2（推荐 7.4 / 8.x）
- 扩展：`json`（必需）、`pdo` + `pdo_mysql` 或 `pdo_sqlite`（使用数据库存储时需要）
- 目录 `config/` 与 `data/` 需可写（安装向导自动检测）

> 没有数据库也能正常使用 —— 选择「文件存储」即可。

## 🚀 安装步骤

1. 上传所有文件到站点目录（本地可直接 `php -S localhost:8000`）
2. 访问 `http://你的域名/install.php`
3. 按向导操作：
   - **第 1 步** 环境检测（红色项需先处理）
   - **第 2 步** 选择存储方式：
     - 文件存储：勾选 `JSON` / `PHP` / `TXT` 格式，可自定义数据目录
     - 数据库存储：MySQL（填主机 / 库名 / 账号）或 SQLite（填数据库文件路径，免安装）
   - **第 3 步** 设置管理员账号，填写姓名、头衔、邮箱，挑选首页与简历模板，并选择**默认语言 / 显示模式 / 主题色**
   - **第 4 步** 完成
4. **安装后请删除 `install.php`**

访问入口：

- 个人主页：`/index.php`
- 在线简历：`/resume.php`（`?print=1` 自动调起打印）
- 管理后台：`/admin/index.php`

## 🌐 多语言

内置 `zh`（简体中文）与 `en`（English）两套语言包，位于 `includes/lang/`。

切换方式（三选一，互相兼容）：

1. 右上角 🌐 图标，访客自选，写入 Cookie 长期生效
2. URL 参数：`/index.php?lang=en`
3. 后台「系统设置 → 外观与语言」设置站点默认值

新增一门语言：复制 `includes/lang/zh.php` 为 `includes/lang/ja.php` 翻译内容，再到 `includes/lang.php` 的 `lang_list()` 里加一行即可，全站（含后台与安装向导）自动支持。

## 🎨 主题面板 / 明暗模式

页面右上角固定三个简约图标：**显示模式**、**主题面板**、**语言**。

### 16 套内置面板

每套面板都是一整套配色（背景、卡片、文字、边框、侧栏、辅助色、光晕），且**明暗各一套**，由主色 + 辅助色 + 中性色相按 HSL 派生，并自动做对比度校正（亮底主色对白 ≥4.6:1，深底主色对深背景 ≥4.6:1）。

| 分组 | 面板 |
|---|---|
| 经典 | 晴空蓝 · 靛青 · 深海青 · 青竹绿 |
| 活力 | 琥珀橙 · 朱砂红 · 玫粉 · 紫罗兰 |
| 自然 | 松林绿 · 湖蓝绿 · 流金 · 摩卡 |
| 沉稳 | 石墨 · 墨黑 · 青梅 · 天蓝 |

- **面板**决定整体氛围（背景/文字/边框/侧栏），**单色**只改主色，两者可叠加：先选面板，再挑一个单色覆盖主色，或点「恢复面板默认色」回到面板原色。
- 选择顺序：访客 Cookie > 后台默认设置 > `azure`。后台「外观与语言」页以分组卡片设置默认值，安装向导第 3 步也可直接挑选。
- 7 套模板全部通过 CSS 变量取色，换面板立即生效，无需改模板。

### 明暗模式

浅色 / 深色 / **跟随系统**。跟随系统用纯 CSS `@media (prefers-color-scheme)` 实现，`<html>` 上的模式与面板由服务端直接输出，**首屏与切换都不会闪白**。

- 简历页打印时强制白底黑字，深色模式不影响导出 PDF
- 右上角控件在打印时自动隐藏
- 「暗色科技」主页模板保持自身深色基调（定义在 `body` 上），同时仍跟随面板主色

### 面板管理（搜索 / 新建 / 删除 / 导入 / 导出）

后台「主题面板」页（侧栏新增入口，也可从「系统设置 → 外观」进入）：

- **搜索**：输入名称、英文名的任意片段即时过滤，右上角控件和后台外观页的选择器里同样带搜索框。
- **新建 / 编辑**：填写标识、中英文名、主色、辅助色、中性色相、分组即可。主色与辅助色决定明暗两套配色，中性色相控制灰阶冷暖；保存后前台立即可选。自定义面板可随时改名、改色。
- **删除**：
  - 自定义面板 → 彻底删除；
  - 内置面板 → **停用**（从选择器与导出列表中移除，可在页面底部「已停用的内置面板」一键恢复），避免误删后无法找回。
  - 若被删除的面板正好是站点默认，会自动回退到 `azure` 并同步主色，前台不会出现空面板。
- **导出**：支持「导出全部（含内置）」「仅导出自定义」「单个面板」，得到标准 JSON，可分享给他人或直接用于备份。
- **导入**：上传 JSON 文件或粘贴文本，三种同名策略：
  - 自动改名（推荐）——内置标识永不覆盖，冲突时另存为新面板；
  - 覆盖同名；
  - 跳过同名。
  兼容多种结构：单个面板对象、`{"panels":[...]}`、`{"panels":{"key":{...}}}`。

导出/导入的面板数据存在 `themes` 数据键下，会随**备份导出导入**和**存储方式迁移**一起走，换数据库、换文件格式都不会丢。

新增内置面板：在 `includes/theme.php` 的 `theme_builtin_panels()` 里加一行（主色、辅助色、中性色相、中英文名），其余配色自动生成。

## 📥 项目区块：手工填写 / 平台自动导入

后台「个人资料 → 项目经历」提供两种录入方式，可混用：

### 方式一：从代码平台自动导入

在页面顶部的「从代码平台导入项目」卡片里选择平台、填写用户名，点击「获取仓库列表」即可拉取公开仓库，随后勾选需要的项，选择**追加到现有项目**或**替换现有项目**。

支持平台：GitHub、Gitee、GitLab、Gitea / 自建实例（可填 API 地址）。

| 仓库字段 | 写入项目 |
|---|---|
| 仓库名 | 项目名称 |
| 描述 | 项目描述 |
| 仓库地址 | 项目链接 |
| 主要语言 / topics | 技术栈 |
| Star 数 | 标签徽章（如 ★ 16.6k，超 1000 显示为 k） |
| 创建 / 更新时间 | 起止时间（年-月） |

导入后每个字段都能继续手工修改，也可以再手工添加新项目。

- **Access Token** 可选：填写后提高接口限流额度，并能读取私有仓库；留空只读公开仓库。
- 一次最多获取 100 个仓库，勾选状态保存在本次会话，可反复调整再导入。
- 已归档仓库会在标签里标注「已归档」，fork 仓库也会被列出，按需勾选即可。

> 接口限流：GitHub 未认证 60 次/小时、Gitee/GitLab 亦有额度。若返回 HTTP 403/429，请填写 Token 或稍后重试；若服务器出口 IP 被平台拒绝，也会是同样的提示。

### 方式二：手工填写

项目区块本身是可增删的重复组，字段：项目名称、担任角色、起止时间、技术栈、标签徽章、项目链接、项目描述。标签徽章可自由填写，如 `★ 128`、`开源`、`已上线`，会渲染成小徽章显示在项目名后面。

## 📊 访问记录

访客打开页面时，前端脚本（Battery Status API / Network Information API 等）会把设备信息上报到 `track.php`，与服务端采集的 IP、UA 合并后存入 `visits`。

| 类别 | 字段 |
|---|---|
| 网络 | IP、来源页、访问页面、在线状态 |
| 设备 | 系统（Windows / macOS / iOS / Android / Linux）、浏览器、屏幕分辨率、DPR、CPU 核数、内存 |
| 网络质量 | `effectiveType`（4g / 3g / wifi）、下行带宽、RTT |
| 电量 | 电量百分比、是否充电中（不支持的浏览器显示 `—`） |
| 环境 | 浏览器语言、时区、是否偏好深色 |

后台「访问记录」页提供：总访问 / 今日 / 独立 IP / 平均电量统计、明细列表（可翻页）、CSV 导出、一键清空。

隐私控制（后台「系统设置 → 访问记录采集」）：

- 可随时关闭采集（关闭后不再写入，历史记录保留）
- 可开启 IP 末段脱敏（`1.2.3.*`）
- 可设置最多保留条数（默认 500，超出自动淘汰旧记录）

> 电量与网络类型依赖浏览器支持（Chrome / Edge 完整支持，Safari 部分支持），不支持时字段留空，不影响其他信息采集。

## 💾 存储方式详解

### 文件存储（默认推荐）

| 格式 | 文件 | 特点 |
|---|---|---|
| JSON | `data/profile.json` | 通用、可读、方便其他程序处理 |
| PHP | `data/profile.php` | `return array(...)`，`include` 直接加载，性能最好 |
| TXT | `data/profile.txt` | PHP `serialize` 序列化文本，体积最小 |

三种格式随时可在后台切换，数据自动转换迁移。访问记录存于同目录的 `visits.*`。

### 数据库存储

- **MySQL / MariaDB**：需提前建库（utf8mb4），安装程序自动建表 `前缀data`
- **SQLite**：单文件数据库，免安装，推荐放在 `data/resume.db`

```sql
CREATE TABLE `pr_data` (
  `dk` varchar(64) NOT NULL,      -- 数据键：profile / settings / visits
  `value` longtext,               -- JSON 内容
  `updated_at` datetime,
  PRIMARY KEY (`dk`)
);
```

## 🧩 模板管理（搜索 / 新建 / 删除 / 导入 / 导出）

后台「模板」页现在是可管理的：

- **搜索**：按名称、标识、说明即时过滤。
- **使用**：每张卡片一个「使用此模板」按钮，点击即生效，无需再点保存。
- **新建**：可以直接粘贴 PHP 源码，也可以先「以此为蓝本」复制任意内置/自定义模板再改。保存时会用 `php -l` 做语法检查，语法错误的模板会被拒绝并提示行号。
- **编辑**：自定义模板可在线改源码、改名、改类型、改标识（改名会同步重建文件）。
- **删除**：
  - 自定义 → 彻底删除（源码文件一并删除）；
  - 内置 → **停用**，可在页面底部「已停用的内置模板」一键恢复。
  - 被删除的模板若正在使用，会自动回退到该类型第一个可用模板。
- **导出**：
  - 「导出全部（含内置）」/「仅导出自定义」→ JSON，源码以字符串内嵌，无需 zip 扩展；
  - 卡片上的下载按钮 → 直接下载单个 `.php` 源码。
- **导入**：上传或粘贴 JSON（含源码），也可以直接粘贴/上传单个 `.php` 文件（此时在上方填写标识、名称、类型）。同名策略：自动改名 / 覆盖 / 跳过，内置标识不会被覆盖。

> 迁移提醒：模板元数据存在 `tplmeta` 键下，会随备份导出导入与存储迁移一起走；但**源码是真实文件**（`templates/custom_*.php`），换服务器时需要连文件一起拷贝，或用上面的导出/导入功能搬运。

## 🔗 多平台拼接获取项目

后台「个人资料 → 从代码平台导入项目」：

- 默认一行「平台 + 用户名 + Token」，点「再加一个平台」可继续添加，**一次最多可拼接任意多个平台**（例如 GitHub 主账号 + Gitee 镜像 + 公司 GitLab），同名用户自动去重。
- 获取数量与**排序方式**可选：

| 排序 | 说明 |
|---|---|
| 时间反 | 最近更新在前（默认） |
| 时间正 | 最早在前 |
| 名称 A→Z / Z→A | 按仓库名字母序 |
| Star 多→少 / 少→多 | 按 Star 数 |

- 合并结果按仓库地址去重（地址为空时按 平台+用户名+仓库名），列表里会标出每个仓库来自哪个平台，勾选后可**追加**或**替换**现有项目。
- 部分平台失败不会中断：成功的照常列出，失败的平台在提示里单独说明（如限流 / IP 被拒）。
- 导入后每个字段仍可手动改，也可以点「手工添加项目」直接在项目区块里自己添加。

## 🔒 安全建议

1. 安装完成**删除 `install.php`**
2. 使用 Nginx 时禁止访问敏感目录：

```nginx
location ~ ^/(config|data)/ {
    deny all;
    return 404;
}
```

Apache 已由安装程序在 `config/` 与 `data/` 下自动生成 `.htaccess` 防护；若未开启 `.htaccess`，请按上例在虚拟主机中另行屏蔽。

3. 访问记录含 IP 等个人信息，建议开启 IP 脱敏并定期清理。

## ❓ 常见问题

**Q：想重新安装怎么办？**
删除 `config/config.php` 与 `data/installed.lock`，再访问 `install.php`。

**Q：忘记管理员密码？**
```bash
php -r '$f="config/config.php";$c=include $f;$c["admin"]["hash"]=password_hash("newpass",PASSWORD_DEFAULT);file_put_contents($f,"<?php\nreturn ".var_export($c,true).";\n");'
```

**Q：切换存储后数据会丢吗？**
不会。切换时会先测试连通性，再把现有资料、设置、访问记录写入新存储，并在 `data/backup-时间戳.json` 留一份备份。

**Q：为什么有些访问没有电量信息？**
Safari、Firefox 等浏览器未实现 Battery Status API，该字段会留空，其余信息照常采集。

**Q：Gitee / GitLab 获取失败提示 HTTP 403？**
多数是限流或服务器出口 IP 被平台策略拒绝。可填写 Access Token 重试，或改用 GitHub；也可直接在项目区块手工填写。

**Q：服务器没有 curl 能自动导入吗？**
可以回退到 `file_get_contents`，但需要 PHP 开启 `allow_url_fopen`；两者都不可用时导入功能不可用（其余功能不受影响）。

**Q：右上角三个按钮（模式 / 主题 / 语言）点了没反应？**
先确认点的是页面右上角固定的那三个按钮。后台模板页的缩略图是 iframe 预览，预览里**不再渲染**这些控件（否则缩略图右上角会出现一套点不动的按钮）。另外控件还带一份内联兜底脚本，即使 `pref.js` 被浏览器缓存或插件拦截，三个按钮仍可正常切换。

**Q：自定义模板换了服务器就没了？**
模板源码是 `templates/custom_*.php` 文件，请连文件一起拷贝；或在模板页「仅导出自定义」得到 JSON，到新站点「导入模板」还原。

**Q：误删了内置主题面板怎么办？**
内置面板不会被真删除，只是停用。到「主题面板」页最下方的「已停用的内置面板」点「恢复」即可。

**Q：能把我的配色分享给别人吗？**
在「主题面板」页点「仅导出自定义」得到 JSON，对方在自己的后台「导入面板」上传即可，同名可选自动改名/覆盖/跳过。

**Q：主题面板和主题色有什么区别？**
面板是一整套配色（背景、文字、边框、侧栏、辅助色），单色只覆盖主色。建议先选面板，需要微调再挑单色。

**Q：可以加自己的模板吗？**
可以。在 `templates/` 下新建模板文件，再到 `includes/schema.php` 的 `template_list()` 中登记即可。模板内可直接使用 `$profile`、`$settings` 及 `t()`、`e()`、`icon()`、`tpl_ml()`、`date_range()` 等辅助函数；CSS 使用 `--bg` / `--text` / `--primary` 等变量即可自动支持深色模式。
